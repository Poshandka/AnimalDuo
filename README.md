# AnimalDuo

简体中文 · [English](README.en.md) · [中文构建说明](docs/BUILD.zh-CN.md)

**游戏在上，岛屿信息在手边。**

AnimalDuo 是面向 **iPad、iPhone 和 Apple Silicon Mac** 的实验性开源项目，针对《集合啦！动物森友会》**3.0.3** 提供兼容运行与交互增强。

以 **iPad 竖屏双屏**为特色，整合地图、背包、图鉴等实时副屏页面，并提供岛民管理、岛屿备份和存档同步工具，让探索、整理和经营岛屿更适合触屏与多设备使用。

项目基于 **nxnative**，沿用源自 **d2r-mobile** 的原生执行方案，并集成 **Eden Duo** 动森副屏模块。游戏代码经适配后在 Apple 芯片上原生执行，图形接口转换为 Metal。

**本项目仅提供源码，需自行准备具有合法来源及相应使用权限的游戏内容并构建。当前主要验证来自 M4 Mac，各平台的验证范围见下文。**

---

**围绕岛屿日常设计的增强功能**

- **iPad 竖屏副屏**  
  上方保留完整游戏画面，下方切换地图、背包、图鉴、DIY、今日和狸端机六个页面，让游戏画面与岛屿信息同时呈现。

- **背包交互**  
  支持物品移动、交换、整理及游戏原生道具菜单。操作会检查物品与游戏状态，可用功能随场景变化。

- **岛民管理**  
  启动游戏前，可从 417 位普通动物岛民中搜索、筛选和替换，也可在已有空地添加岛民，或删除岛民并保留空地。维持原版 10 位上限，每次修改前自动备份完整存档。

- **岛屿备份与恢复**  
  创建命名检查点、查看备份历史、恢复完整岛屿。恢复前自动备份当前进度；恢复操作会同时回退玩家与岛屿数据。

- **存档同步工具**  
  通过用户选择的共同云文件夹共享完整检查点，支持冲突选择和本机离线继续。真实跨设备云传输仍待验证；两份独立进度不能自动合并。

- **实验性局域网互访**  
  匹配版本之间提供搜索、开岛、登岛和返程功能。已完成同一台 Mac 上双进程互访验证，真实双设备 Wi-Fi 场景仍待验证。

- **触控与手柄适配**  
  支持实体手柄、部分震动适配、横竖屏独立触控布局，以及按键显隐和自动淡出。持续优化副屏刷新、着色器预热、缓存与图形资源管理。

AnimalDuo 的适配工作主要围绕 Apple 平台副屏呈现、背包交互、岛民与存档管理、触控布局，以及运行体验修复展开。底层运行框架和副屏模块的来源见文末致谢。

**平台与验证范围**

| 目标平台 | 主要体验 | 当前验证范围 |
|---|---|---|
| **iPad** | 竖屏副屏、横屏游玩、触控操作和管理界面 | 本版本实机与长时间验证待补充 |
| **iPhone** | 横屏游玩、触控与手柄操作 | 本版本实机与长时间验证待补充 |
| **Apple Silicon Mac** | 原生启动器、共享岛屿存档 | 现有主要验证来自 M4 Mac |

Mac 启动器暂未提供 Swift 岛民管理界面，但可加载已经编辑的岛屿存档。系统、工具链及设备要求请参阅构建说明。

游戏保持原版约 **30 帧**的目标。着色器预热覆盖已记录的场景，其他场景仍可能触发首次编译。长时间反复进出房屋曾出现加载就绪超时，原因尚未确定。

项目未实现任天堂官方在线服务、与原版 Switch 直接联机或直接岛屿迁移。同步续玩时，建议一次只在一台设备上游玩，正常保存并等待云文件上传完成后再切换。

详细测试记录与已知问题见[动森适配说明](https://github.com/ShawndYang/AnimalDuo/blob/main/dm/games/01006F8002326000/README.md)。
