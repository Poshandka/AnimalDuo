# AnimalDuo

简体中文 · [English](README.en.md) · [中文构建说明](docs/BUILD.zh-CN.md)

**游戏在上，岛屿信息在手边。**

AnimalDuo 是面向 **iPad、iPhone 和 Apple Silicon Mac** 的动森增强开源项目，以竖屏双屏、实时岛屿信息和触控操作为特色，整合背包交互、岛民管理、云存档和同版局域网互访。

当前公开源码对应 **应用 3.0.51 / 游戏 3.0.3**。项目基于 [nxnative](https://github.com/seedds/nxnative)，沿用源自 [d2r-mobile](https://github.com/jhaizhou-ops/d2r-mobile) 的原生执行方案，并集成 [Eden Duo Companions](https://github.com/igawa6/eden-duo-companions)。游戏代码经适配后在 Apple 芯片上执行，图形接口转换为 Metal。

[下载 3.0.51 源码](https://github.com/ShawndYang/AnimalDuo/releases/tag/v3.0.51) · [本版更新说明](RELEASES/3.0.51.md) · [中文构建说明](docs/BUILD.zh-CN.md)

## 主要功能

| 功能 | 内容 |
|---|---|
| 竖屏双屏 | iPad 竖屏显示上方游戏、下方副屏；Duo 展开竖屏主副屏各占一半，横屏显示游戏。 |
| 六页实时副屏 | 地图、背包、生物图鉴、DIY、今日信息、狸端机；查看位置、岛民、物品、材料和部分每日任务。 |
| 背包操作 | 点选或拖动交换物品、分类整理，调用游戏原生的使用、装备、摆放及拆分菜单，并通过游戏保存。 |
| 屏幕按键 | 左右侧框内居中排列，2D／3D 切换，横竖屏分别调整位置、大小、透明度和死区；默认持续显示，可选淡化或隐藏。 |
| 原生触控 | 已适配的游戏内键盘与公告栏绘画接收屏幕触摸；横屏在原生操作期间让出按键，竖屏保留下方按键。 |
| 岛民管理 | 417 位普通动物，中英文搜索及分类筛选，替换、空地添加、删除；保留 10 位上限，修改前自动备份完整存档。 |
| 备份与云存档 | 命名备份、完整恢复，用户选择共同的 iCloud 文件夹，保存后发布完整快照，支持冲突选择、重试和本机继续。 |
| 实验性局域网 | 同版原生移植端之间搜索、开岛、访问和返程；不接入任天堂官方在线服务。 |
| 画面适配 | 普通 iPhone 全屏横屏、Duo 内外屏切换、按实际比例扩展渲染；保留完整画面模式。 |
| 小包更新 | 大资源首次安装后保留，兼容的后续更新可复用资源；3.0.51 本地薄更新包约 46 MB，公开下载为源码。 |
| 性能优化 | 扩大已记录场景的着色器预热，合并重复加载，修复退休线程栈及纹理视图回收，限制副屏缓存并减少隐藏页面刷新。 |
| 平滑与诊断 | 可选平滑显示，移动端默认关闭、过热自动停用；提供帧时间、内存、温控和手柄震动诊断。 |

## 3.0.51 更新

- 副屏默认按键约放大 15%，完整绘制和触控区域保持在左右侧框内。
- ＋／−上移到两组操作之间，L3／R3移到底部功能排。
- 切换副屏页面、操作物品、打开菜单和上屏打字／绘画时，竖屏按键持续显示并保留按住的输入。
- 保留 iPhone 全屏横屏、Duo 主副屏布局、已有资源和存档格式。

本次公开以冻结的 3.0.51 源码为准，未混入后续开发中的默认 3D 迁移、占用蒙版扩展或手机应用铺满修改。

## 平台与验证范围

| 平台 | 主要体验 | 验证边界 |
|---|---|---|
| iPad | 竖屏副屏、横屏游戏、触控与管理界面 | 新版实体设备与长时间表现仍需验证。 |
| iPhone | 普通手机固定横屏，触控及手柄操作 | 原生 iPhone 17 模拟器完成布局与输入检查；不等于实体游戏测试。 |
| Duo | 外屏横屏、内屏四方向及竖屏 50/50 | 原生模拟器完成反复旋转和折叠检查；反向横屏折叠后的绝对朝向仍有已知问题。 |
| Apple Silicon Mac | 原生宿主、共享岛屿存档 | 主要游戏与性能验证来自 M4 Mac；原生 Mac 启动器不提供 Swift 岛民管理界面。 |

游戏维持原版约 30 帧目标；平滑显示不改变游戏模拟速度。预热覆盖已记录状态，未覆盖场景仍可能首次编译。部分超宽 UI 裁切、偶发房屋加载停滞和帧时间尖峰尚待解决，不能保证所有场景或长时间游玩都无卡顿、无闪退。

局域网已完成同一台 Mac 的双游戏进程互访，实体双设备 Wi-Fi 仍待验证。云存档已检查完整快照、冲突和恢复，真正跨设备的 iCloud 传输仍待全面验证；同步续玩时一次只在一台设备游玩。Xbox USB 无震动仍未解决，蓝牙修复的最终游戏输出仍需确认。“我的设计”画布直接触摸尚未完成。

不支持任天堂官方在线联机、原版 Switch 互访或官方岛屿迁移。详细边界见[动森适配记录](dm/games/01006F8002326000/README.md)。

## 获取源码与构建

```sh
git clone --depth 1 --branch v3.0.51 https://github.com/ShawndYang/AnimalDuo.git
cd AnimalDuo
```

构建步骤见[中文构建说明](docs/BUILD.zh-CN.md)及[英文源码说明](PUBLIC-SOURCE.md)。本仓库保留完整动森配置、运行宿主、构建工具和组件许可；其他游戏的大型配置及截图图库不在此专用源码中，少量元数据仅供工具回归测试。

公开内容为源码，不是可直接游玩的安装包。自行准备匹配的游戏本体、3.0.3 更新、所需 DLC、字体和主机密钥，并放在源码目录之外。
