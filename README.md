# AnimalDuo

简体中文 · [English](README.en.md) · [中文构建说明](docs/BUILD.zh-CN.md)

**游戏在上，岛屿信息在手边。**

AnimalDuo 是面向 **iPad、iPhone 和 Apple Silicon Mac** 的动森增强开源项目，将实时地图、背包、DIY、岛民管理和存档工具整合到触控界面。

**AnimalDuo 1.1** 对应应用构建 **3.0.59**、游戏 **3.0.3**。本版完善 iPad 全屏与竖屏双屏布局、手机应用界面和场景过渡，并为兼容版本之间的局域网互访加入 **30／60 秒暂离等待**。

项目基于 [nxnative](https://github.com/seedds/nxnative)，沿用源自 [d2r-mobile](https://github.com/jhaizhou-ops/d2r-mobile) 的原生执行方案，并集成 [Eden Duo Companions](https://github.com/igawa6/eden-duo-companions)。游戏代码经适配后在 Apple 芯片上执行，图形接口转换为 Metal。

[下载 1.1 源码](https://github.com/ShawndYang/AnimalDuo/releases/tag/v1.1) · [本版更新说明](RELEASES/1.1.md) · [中文构建说明](docs/BUILD.zh-CN.md)

> **这里下载的是源码，不能直接安装。** 请自行准备匹配的游戏资源并构建；首次安装与已有安装升级的步骤见[构建说明](docs/BUILD.zh-CN.md)。

## 主要功能

| 功能 | 内容 |
|---|---|
| 竖屏双屏 | iPad 和 Duo 展开竖屏时主副屏各占一半，横屏铺满游戏；保留完整画面模式。 |
| 六页实时副屏 | 地图、背包、生物图鉴、DIY、今日信息、狸端机；查看位置、岛民、物品、材料和部分每日任务。 |
| 背包操作 | 点选或拖动交换物品、分类整理，调用游戏原生的使用、装备、摆放及拆分菜单，并通过游戏保存。 |
| 屏幕按键 | 左右侧框内居中排列，2D／3D 切换，横竖屏分别调整位置、大小、透明度和死区；默认 3D 且持续显示，可选 2D、淡化或隐藏。 |
| 原生触控 | 已适配的游戏内键盘与公告栏绘画接收屏幕触摸；横屏在原生操作期间让出按键，竖屏保留下方按键。 |
| 岛民管理 | 417 位普通动物，中英文搜索及分类筛选，替换、空地添加、删除；保留 10 位上限，修改前自动备份完整存档。 |
| 备份与云存档 | 命名备份、完整恢复，用户选择共同的 iCloud 文件夹，保存后发布完整快照，支持冲突选择、重试和本机继续。 |
| 实验性局域网 | 兼容原生移植端之间搜索、开岛、访问和返程；全员支持时可暂离等待 30／60 秒。 |
| 画面适配 | 普通 iPhone 全屏横屏、Duo 内外屏切换、按实际比例扩展渲染；保留完整画面模式。 |
| 小包更新 | 大资源首次安装后保留，兼容的后续更新可复用资源；3.0.59 本地薄更新包约 45.8 MB，公开下载为源码。 |
| 性能优化 | 扩大已记录场景的着色器预热，合并重复加载，修复退休线程栈及纹理视图回收，限制副屏缓存并减少隐藏页面刷新。 |
| 平滑与诊断 | 可选平滑显示，移动端默认关闭、过热自动停用；提供帧时间、内存、温控和手柄震动诊断。 |

## 1.1 更新

- **画面适配：** iPad 横屏铺满、竖屏主副屏各半；修正扩展画面下时钟、小地图和狸端机裁切，补齐 DIY、里程任务及“我的设计”等界面背景。
- **转场覆盖：** 黑色、白色及半透明遮罩跟随画面扩展，改善进入游戏、进出房屋与机场过渡时露出场景边缘的问题。
- **按键体验：** 默认 3D；旧 2D 配置首次升级迁移一次，后续手动选择仍保留。L3／R3 上移，名字键盘确认后恢复横屏按键。
- **副屏布局：** 占用蒙版覆盖左右区域；连接手柄时利用腾出的空间展示更多副屏内容。
- **联机连接：** 优先选择可用的私有局域网接口，修复被链路本地地址抢先选中时“能发现岛屿、无法出发”的已定位原因。
- **暂离等待：** 默认 30 秒，房主可选 60 秒；全员暂停、倒计时、返回后自动确认就绪并恢复，也可主动结束。额外暂离不重置当前倒计时。
- **延续已有功能：** 六页副屏、背包交互、417 位普通岛民管理、备份与云存档、预热及兼容小包更新继续保留。

联机暂离等待需要房间内所有设备支持。旧版仍可普通联机，但会关闭房间的暂离等待。iOS 提前结束进程或网络中断仍可能导致断线；该功能不提供无限后台运行。更新细节和验证边界见 [1.1 更新说明](RELEASES/1.1.md)，上一版保留在 [3.0.51 历史说明](RELEASES/3.0.51.md)。

## 从 1.0 升级

AnimalDuo **1.0／构建 3.0.51 → 1.1／构建 3.0.59**，游戏内容仍为 **3.0.3**。

1. 先在现有版本导出完整存档备份，再准备并构建 1.1。
2. 更新已有安装时保持相同安装身份与应用数据容器；不要先卸载原应用。兼容的已安装资源可复用，薄更新无法独立完成首次安装。
3. 使用联机暂离等待时，让所有参与设备升级到支持该功能的构建。返回后会自动协商恢复，无需手动点击“就绪”。

## 平台与验证范围

| 平台 | 主要体验 | 验证边界 |
|---|---|---|
| iPad | 横屏铺满、竖屏各半、触控与管理界面 | 新版实体设备与长时间表现仍需验证。 |
| iPhone | 普通手机固定横屏，触控及手柄操作 | 原生 iPhone 17 模拟器完成布局与输入检查；不等于实体游戏测试。 |
| Duo | 外屏横屏、内屏四方向及竖屏 50/50 | 原生模拟器完成反复旋转和折叠检查；反向横屏折叠后的绝对朝向仍有已知问题。 |
| Apple Silicon Mac | 原生宿主、共享岛屿存档 | 主要游戏与性能验证来自 M4 Mac；原生 Mac 启动器不提供 Swift 岛民管理界面。 |

iPad 与 Duo 展开竖屏提供六页副屏和岛民管理界面；普通 iPhone 固定横屏，不显示竖屏副屏；Mac 使用原生宿主，当前不提供 Swift 岛民管理界面。各平台的功能与验证范围不同。

游戏维持原版约 30 帧目标；平滑显示不改变游戏模拟速度。预热覆盖已记录状态，未覆盖场景仍可能首次编译。未覆盖的界面／场景、偶发房屋加载停滞和帧时间尖峰仍需继续检查，不能保证所有场景或长时间游玩都无卡顿、无闪退。

局域网已完成同一台 Mac 的双游戏进程互访，以及 15／35 秒暂停恢复、同时暂离和 60 秒超时处理；实体双设备 Wi-Fi 与真机后台恢复仍待验证。云存档已检查完整快照、冲突和恢复，真正跨设备的 iCloud 传输仍待全面验证；同步续玩时一次只在一台设备游玩。Xbox USB 无震动仍未解决，蓝牙修复的最终游戏输出仍需确认。“我的设计”画布直接触摸尚未完成。

不支持任天堂官方在线联机、原版 Switch 互访或官方岛屿迁移。详细边界见[动森适配记录](dm/games/01006F8002326000/README.md)。

## 获取源码与构建

```sh
git clone --depth 1 https://github.com/ShawndYang/AnimalDuo.git
cd AnimalDuo
```

main 包含发布后的 SDK 兼容、震动测试与 Python 检查修复；v1.1 标签和发布页下载保留原始冻结源码。构建步骤见[中文构建说明](docs/BUILD.zh-CN.md)及[英文源码说明](PUBLIC-SOURCE.md)。本仓库保留完整动森配置、运行宿主、构建工具和组件许可；其他游戏的大型配置及截图图库不在此专用源码中，少量元数据仅供工具回归测试。

公开内容为源码，不是可直接游玩的安装包。自行准备匹配的游戏本体、3.0.3 更新、所需 DLC、字体和主机密钥，并放在源码目录之外。
