Animal Crossing 3.0.3 starter-dialogue and resident-initialization update (2026-10-30)

Read the retained BUILD-RESOURCE-OPTIMIZED.txt and earlier build instructions for proprietary input preparation, the native core, companion sources, the unchanged shader chain and unsigned Apple packaging. This update adds a generated early-dialogue resource overlay and fixes fresh resident memories. It also includes the separately validated shared NVN secondary-view lifetime fix developed before the resident bug took priority. No game assets, original saves or keys are included in the corresponding source.

Dialogue overlay
The source game never assigns six of its eight personalities to the original two settlers. Identity-only resident replacement exposes missing early-story text and BDLI cues. Do not change BirthType to avoid that text: the same origin controls NPC house construction. The selected fix retains origin, houses, loan/build state, gifts and all player memories, supplies only absent/empty early-story labels, and preserves existing nonempty dialogue and cue bytes. These otherwise absent lines reuse the original gender-matched starter's localized wording; ordinary personality dialogue is unchanged.

With libzstd available, run from the source root:
python3 scripts/build_acnh_starter_dialogue.py /external/game/RomFS /external/game/dialogue-overlay --report /external/game/dialogue-overlay.json --merged-romfs /external/game/dialogue-RomFS
python3 scripts/build_acnh_starter_dialogue.py /external/game/dialogue-RomFS --verify

Use ROMFS=/external/game/dialogue-RomFS, DM_CONTROL_NACP=/external/game/control.nacp and the existing DM_RESIDENT_CATALOG/DM_RESIDENT_LICENSE inputs with dm/ios/tools/build_ipa.sh. The explicit original control metadata retains the game's language capabilities even though RomFS has moved. The build requires the complete, verified 3.0.3 overlay when the resident manager is enabled. Pass the same merged folder to the native Mac packer's --romfs option. APFS clones avoid duplicating unchanged game files; the input extraction is read-only. The overlay has 14 locale archives and 420 synchronized BDLI files, including missing files, for 2,268 missing messages. SARC/MSBT/BDLI formats are checked on read and round trip; Zstandard content sizes are declared for the game loader. The source tool and its synthetic tests contain no game dialogue.

Resident defaults
Addition copies only the unassigned second template memory suffix, restores local player identities, and assigns friendship 25 only where a real town/player ID exists. Its unassigned identity format byte is not a player ID. The donor's first-memory acquaintance, custom greeting and dates are not imported. Replacement, deletion, stale-writer protection, atomic main.dat updates, whole-save backup and atomic restore keep their existing behavior.

Validation
Run python3 -m unittest dm.tools.tests.test_acnh_starter_dialogue dm.ios.tests.test_resident_save -v. The encrypted fixture verifies all eight replacement personalities, origin/house/player-memory preservation, fresh defaults, ten-resident capacity, duplicate/moving/format/hash/stale-write guards and restoration. The format tests check archive alignment/lookup, opaque UTF-16 controls, attributes, cue CRC/relative offsets, fixed-size compression frames, empty/missing-only changes, nonempty preservation and idempotence. Run the iOS suite with python3 -m unittest discover -s dm/ios/tests -v. Source Git fixture tests use an external GIT_INDEX_FILE; rebuild it before the environment registry check. Never modify the developer's real index.

The native M4 fixture uses copied islands and ordinary controller input with read-only actor tracking. Numeric reports show the old blank body, two nonempty repaired early-story pages and a separate same-permission/next-day NPC housing test. Inputs that get caught against a tree/house or encounter a fishing-only reaction are incomplete navigation cases, not completed dialogue routes or engine crash claims. Screenshots, raw game messages and player data stay in external NSP scratch. The full regression report separately checks the only local game's shader chain and two startup routes per revision; it is not a physical-iPad or sustained-FPS guarantee.

Shared lifetime fix
The included t_pool_views.m exercises actual Metal primary/compatible/image views, their pool retirement and GPU pixels. Its 32-texture control retains 32 views and 32 MiB more allocated GPU storage before the fix, then retains zero retired views after the fix. This is a constructed ownership result, not a measured whole-game RAM saving. The changed renderer/fixture pass scoped ASan/UBSan with the packed registration translation unit uninstrumented because sanitizer redzones break its section layout. Long scene automation also had an unresolved loading-readiness incident on the previous host; a subsequent 30-minute previous-host route completes, but its presentation record is incomplete. No claim that the lifetime fix resolves that incident is made. See validation/lifetime and the game note for the limits.

The iOS IPA remains generic arm64, iPad+iPhone, minimum iOS 26, unsigned, with no signing or installation on a player's device. The Mac core is generic Apple-m1 arm64, minimum macOS 27, ad-hoc signed and not notarized. Both packages retain the original application IDs and unchanged shaders, font bytes, seed and other game resources. The native Mac launcher has no Swift resident-manager UI; it consumes the same edited save and dialogue overlay.
