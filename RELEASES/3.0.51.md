# AnimalDuo 3.0.51：副屏按键与多端适配

应用版本 **3.0.51**，对应《集合啦！动物森友会》**3.0.3**。本次提供经过隐私检查的源码快照，发布日期为 2026 年 11 月 3 日。

## 本版改进

- 竖屏副屏默认按键约放大 15%，保持在左右框内居中，避免触及中间内容。
- ＋／−移到上下两组操作之间；L3／R3放到底部功能排，短屏幕保留菜单按键的可触控尺寸。
- 点击按键、切换副屏、操作物品或打开原生菜单时，竖屏按键持续显示并保留按住的输入。
- 上屏使用游戏内键盘或公告栏绘画时，下屏按键继续可用；横屏仍按原生触控状态自动让出按键。

## 同步自上次公开源码以来的改进

- 普通 iPhone 全屏横屏及扩展渲染；Duo 原生旋转、合拢展开后的布局恢复、竖屏主副屏各半。
- 屏幕按键菜单、默认持续显示、左右共享框与底栏布局、绘画结束后的输入恢复。
- 扩展画面下的圆形场景转场修复，以及副屏狸端机图标材质与颜色校正。
- 大资源保留与兼容薄更新，游戏保存后的云快照发布和状态处理改进。
- 线程栈回收、预热重复加载合并、更多实际场景预热、性能记录目录修复。
- 保留六页副屏、背包交互、417 位岛民管理与对话修复、备份恢复、同版局域网和手柄适配。

## 验证与已知问题

3.0.51 的历史本机验证包含原生布局／输入／边界检查、宿主与图形测试、全部 9,766 个着色器对比及两次 90 秒启动路线。它们不等于实体移动设备或数小时稳定性验证；本次源码发布不新增游戏性能结论。

尚未解决：Duo 反向横屏折叠后的绝对朝向、部分超宽 UI 裁切、偶发房屋加载停滞和帧时间尖峰；Xbox USB 无震动；“我的设计”画布原生触摸。真实跨设备 iCloud 传播和双设备 Wi-Fi 联机仍待全面验证。不支持任天堂官方在线服务或原版 Switch 联机。

本版不包含后续开发中的默认 3D 迁移、占用蒙版扩展和手机应用铺满调整。
