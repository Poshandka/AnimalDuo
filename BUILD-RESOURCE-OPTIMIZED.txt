Animal Crossing 3.0.3 Apple resource-index update (2026-10-30)

Read the retained BUILD-SCENE-PREWARM.txt, BUILD-SHADER-PREWARM.txt and earlier build instructions for dependencies, proprietary input preparation, companion sources and unsigned Apple packaging. This release changes the shared NVN renderer, its tests and finding documentation. The translator, shader libraries, expanded 800-library/727-render/6-compute seed, game rewriting and UI/save behavior are unchanged. No game assets, original saves or keys are included in the corresponding source.

Implementation
The first nonempty pool_find builds the sorted dense-index array. pool_index_insert maintains the upper bound when mtl_pool_add appends a pool. pool_index_position finds the exact identity through lower-bound search plus an equal-start run. pool_index_remove deletes that sorted entry and fixes the ID of the dense table's moved last element. Additions no longer advance g_pool_gen: existing cached mappings remain valid. Deletions still invalidate thread caches; argument-buffer registration generation, residency and deferred object retirement are unchanged. There is one index entry per live pool, with the prior capacity high-water allocation behavior.

The new fixture includes the production renderer and uses real Metal NoCopy registrations and an independent live-range oracle. It exercises empty queries, unsorted registrations, overlapping/equal-start aliases, dense-table moves, random mutations and address reuse while an old resource remains held. The gated concurrent-reader case intentionally fails on the old implementation because a disjoint addition invalidates its address cache and sends it to a mutex held by the writer. All old address-oracle checks pass.
For ASan/UBSan, compile hle_nvn.c separately without instrumentation and link it with the sanitized renderer, fixture and remaining sources. Its packed Mach-O registration section relies on adjacent entries; sanitizer global redzones break the section before main. This scoped instrumentation is disclosed in unit-controls-final.json. Do not describe the entire host as sanitized.

Keep published releases and original saves. Only a uniquely named, successfully verified extraction copy may be removed.
